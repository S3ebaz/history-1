# Ecos de México  
### Línea de tiempo interactiva · Historia de México

Sitio web interactivo que presenta la **Historia de México desde el Caudillismo (1821) hasta el presente**.

Al hacer clic en cada época se despliega un “expediente histórico” con:
- Resumen claro y organizado
- Datos clave
- Imágenes ilustrativas
- Notas de contexto

Ideal para repaso escolar o consulta rápida.

---

## Épocas incluidas

| Periodo | Años | Contenido principal |
|---------|------|---------------------|
| **Caudillismo** | 1821 – 1876 | Santa Anna, pérdida de territorio, Reforma liberal, Juárez |
| **Porfiriato** | 1876 – 1911 | Dictadura de Díaz, ferrocarriles, desigualdad social |
| **Revolución Mexicana** | 1910 – 1920 | Madero, Zapata, Villa, Carranza, Constitución de 1917 |
| **México Postrevolucionario** | 1920 – 1940 | Guerra Cristera, Maximato, PNR, Cárdenas, Expropiación Petrolera |
| **México Contemporáneo** | 1940 – actualidad | Milagro Mexicano, 1968, TLCAN, alternancia democrática |

## Cómo ver el sitio

### Opción 1 – Local
1. Descarga el archivo `index.html`
2. Ábrelo con cualquier navegador (Chrome, Firefox, Edge, etc.)

### Opción 2 – En línea (GitHub Pages)
Una vez publicado, el sitio estará disponible en:

```
https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/
```

---

## Características

- Diseño tipo “expediente histórico” (papel envejecido)
- Línea de tiempo horizontal con filtros por categoría
- Información tomada de apuntes de clase
- Totalmente responsive (se adapta a celular y computadora)
- Sin dependencias externas (solo HTML + CSS + JavaScript)

---

## Cómo publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub
2. Sube el archivo como `index.html`
3. Ve a **Settings → Pages**
4. En *Source* selecciona la rama `main` y la carpeta `/ (root)`
5. Guarda y espera 1-2 minutos

Tu sitio estará listo.
